# Publish ARTIQ

This demo is a static site: no build step and no dependencies.

## Vercel
1. Create a new project.
2. Upload/import this folder.
3. Framework preset: **Other**.
4. No build command is required.
5. Deploy.

## Netlify
1. Create a new site.
2. Deploy this folder using Netlify's manual deploy or connect a repository containing it.
3. The included `netlify.toml` publishes the project root.

## Before public launch
Replace demo comparable sales with licensed/verified market data; add authentication, persistent storage, evaluator credentialing, privacy/terms, secure document handling, and appropriate appraisal/authentication disclosures.
